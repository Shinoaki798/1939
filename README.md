# 1939 — The Shape of a Knowledge Boundary

APS360 (UofT, Fall 2026) individual project by Junlei An.
One decoder-only Transformer trained from scratch on newspaper text ending
1939-06-30, used to characterise the structure of its own knowledge boundary.
